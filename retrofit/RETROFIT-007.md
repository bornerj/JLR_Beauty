RETROFIT-007 — Performance de Serviços

A mesma lógica, mas serviço não pode usar apenas margem × volume.

Serviços têm uma variável essencial:

tempo.

Então:
```
SERVIÇOS

              ALTO R$/HORA
                   ↑

 Premium Color     │       Mega Hair
                   │
───────────────────┼────────────────────→ DEMANDA
                   │
 Serviço A         │       Serviço B
                   │
              BAIXO R$/HORA
```
E teremos:
```
Receita/hora
Margem/hora
Duração média
Ocupação
Reagendamento
No-show
Recorrência
```
Pode surgir um insight como:
```
⚠ Serviço X vende bastante,
mas ocupa 18% da capacidade da agenda
e representa apenas 8% da margem.

[Analisar preço]

```
